## 🕹️ About

Onimusha: Way of the Sword is a swordplay action game set in a dark-fantasy version of Edo-period Kyoto. Players control Miyamoto Musashi, a samurai wielding the mystical Oni Gauntlet, as he battles Genma monsters and uncovers the mystery behind Kyoto’s transformation. The game is scheduled for release on September 4, 2026.

This game is for players who enjoy cinematic samurai combat, dark fantasy adventures, and challenging single-player action.
